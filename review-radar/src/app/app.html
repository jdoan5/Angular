Pipeline: Apple RSS reviews feed → bronze (raw, append-only) → silver (MERGE-deduped, one row per review) → gold aggregates → nightly JSON snapshot → this page. Built on Databricks Free Edition; orchestrated by a Lakeflow job; deployed via Asset Bundles.

This demo publishes aggregate numbers only — no review text, no author names. Not affiliated with Apple or any listed app.
